# Tienda Don Pedro

Sistema sencillo para organizar la información de la tienda de barrio de Don Pedro.

## ¿Qué vende Don Pedro?

La tienda ofrece productos básicos para el hogar, como:

- Leche
- Pan tajado
- Huevos
- Café
- Panela
- Arroz

También ofrece servicios de fiado, descuentos para clientes frecuentes y domicilios.

## Organización del proyecto

La información está organizada en la carpeta `datos`.

| Archivo | Descripción |
|---|---|
| productos.txt | Productos y precios |
| clientes.txt | Registro de clientes |
| fiado.txt | Registro de fiados |
| datos.txt | Información de la tienda |
| domicilios.txt | Barrios y precios de domicilios |
| descuentos.txt | Descuentos para clientes frecuentes |
